## Architecture decisions
_Major design choices with rationale. The "why" matters more than the "what" for future sessions._

- **Leaflet via CDN (não react-leaflet):** Mapa usa vanilla Leaflet via `window.L` global, não o pacote npm. Decisão existente no projeto.
- **Mapa recriado a cada mudança de praça:** Usa `key` prop no container do mapa para forçar teardown/rebuild completo do Leaflet ao trocar de praça.
- **Multi-tenant com square_id:** Praças (Square) são a unidade de filtragem em todos os endpoints admin. Cada endpoint aceita `?square_id=` como query param opcional.
- **Super admin com campo `is_super_admin` (não `tenant_id is None`):** Usar booleano explícito no modelo User. O padrão antigo (`tenant_id is None`) era vulnerável — a rota `PUT /api/platform/users/<id>` permitia setar `tenant_id=None` e promover qualquer admin a super admin acidentalmente. Decisão: campo explícito + endpoint protegido `/setup-super-admin` com `ADMIN_SETUP_TOKEN`.
- **Registro contínuo na memória:** Registrar toda modificação ou ajuste na memória do projeto imediatamente, mesmo antes de commit, para manter memória sempre atualizada.
