PR
Praça (Square)
Unidade de organização regional · Agrupa estabelecimentos e entregadores por cidade/região
ENTIDADE DO SISTEMA ▼
📌 O que é uma Praça?
  • Definição: Uma praça é uma região geográfica de atuação (ex: Capão da Canoa/RS, Porto Alegre/RS)
  • Função: Agrupa estabelecimentos, entregadores e pedidos de uma mesma área
  • Filtragem: Todo o dashboard admin filtra por praça — cada dado pertence a uma praça
  • Tabela de preço: Cada praça pode ter sua própria tabela de preços de entrega
📋 Campos da Praça
  • name — Nome da praça (ex: "Capão da Canoa")
  • city — Cidade (ex: "Capão da Canoa")
  • state — Estado (ex: "RS")
  • is_active — Se a praça está ativa
  • tenant_id — Organização à qual pertence
🔗 Relacionamentos
  • Estabelecimentos (Restaurant) — cada estabelecimento pertence a uma praça via square_id
  • Entregadores (Driver) — entregadores operam em uma praça via square_id
  • Pedidos (Order) — pedidos são filtrados pela praça do estabelecimento
  • Tabela de Preço (PricingTable) — tabela vinculada à praça
  • Preço Dinâmico (DynamicPricing) — regras de preço por praça
⚡ Como é Usada no Sistema
  • Seletor no Layout: Admin seleciona praça ativa no topo — todos os dados filtram automaticamente
  • Query param: Endpoints aceitam ?square_id=X para filtrar resultados
  • Auto-roteirização: Motor de rotas agrupa pedidos por praça para otimizar entregas
  • Mapa do dashboard: Centraliza na cidade da praça selecionada
  • Cadastro de entregador: Entregador é vinculado a uma praça ao se cadastrar

EV
Entregador Próprio
Contratado do estabelecimento · Faz entregas apenas do seu estabelecimento
POR ESTABELECIMENTO ▼
📝 Cadastro & Login
  • Cadastrado pelo estabelecimento — admin ou estabelecimento cria o cadastro
  • Login próprio — rota separada /own-driver/login com token próprio POST /api/own-driver/login
  • Dados: nome, telefone, tipo de veículo
  • Praça herdada — não tem square_id próprio; herda do estabelecimento via Restaurant.square_id
  • Segurança — verificação de ownership: CLIENT só acessa drivers do seu próprio restaurante
📦 Entregas
  • Receber pedidos — designados pelo estabelecimento (não por oferta)
  • Visualizar pedidos — lista de entregas atribuídas GET /api/own-driver/orders
  • Aceitar/Rejeitar — confirma ou recusa a entrega
  • Confirmar coleta — marca que coletou no estabelecimento POST /api/own-driver/orders/:id/collect
  • Confirmar entrega — marca que entregou ao cliente POST /api/own-driver/orders/:id/deliver
  • Enviar prova — foto de comprovação
💰 Ganhos
  • Visualizar ganhos — entregas realizadas e valores GET /api/own-driver/earnings
  • Histórico — todas as entregas com detalhes
  • Pagamento — controlado pelo estabelecimento/admin
🗺️ Rotas
  • Mapa de entrega — rota até o cliente
  • Otimização — quando há múltiplas entregas simultâneas
  • Visualização de rotas — histórico de rotas percorridas GET /api/own-driver/routes
Resumo dos Blueprints (Rotas da API)
Blueprint Prefixo Responsável por Quem usa
auth_bp /api/auth Login, registro, perfil, alteração de senha Todos os usuários
driver_bp /api/driver Status, localização, estatísticas, ganhos, ranking, conquistas Entregador Plataforma
order_bp /api/orders Criar pedidos, listar, aceitar, rejeitar, atualizar status, avaliar Estabelecimento + Entregadores
admin_bp /api/admin Dashboard, CRUD de tudo (estabelecimentos, praças, entregadores, pedidos, financeiro, relatórios, usuários) Admin + Super Admin
platform_bp /api/platform Dashboard global, CRUD de tenants e admins, setup super admin Super Admin
webhook_bp /api/webhooks Receber webhooks de plataformas externas (iFood, etc.) Sistema (externo)
own_driver_bp /api/own-driver Login, pedidos, coleta, entrega, ganhos, rotas do entregador próprio Entregador Próprio
route_bp /api/routes Rotas de entrega, otimização, paradas Admin + Entregadores
finance_bp /api/finance Financeiro avançado, faturas, assinaturas Admin

Segurança e Multi-tenant

  • Verificação de tenant inativo em login, admin e pedidos
  • Usuário suspenso/inativo bloqueado em todas as rotas
  • Filtro de tenant em todas as queries críticas
